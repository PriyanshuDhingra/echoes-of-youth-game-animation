# Graphics and Visual Computing Project - Animating God of War Game Scene

This project is a 3D character and environment study created in Autodesk Maya, inspired by the visual language of God of War. The repository includes the main Maya scene, textured assets, exported FBX models, presentation slides, and the final gameplay-focused animation video.

## Project Overview

This project focuses on:

- 3D character modeling and sculpting workflow
- Texture and material creation
- Scene composition and lighting setup
- Asset export for presentation and sharing
- Final animation/video showcase for project evaluation

## How to Open the Project

1. Open Autodesk Maya 2023.
2. Load the main scene: `21IT3022(Priyanshu Dhingra)_GVC_Project.mb`.
3. Use `workspace.mel` to reference the project structure if needed.
4. Reconnect texture paths if the project is opened on another machine.
